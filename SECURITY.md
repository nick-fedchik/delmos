# Політика безпеки та повідомлення про вразливості (Security Policy)

Цей документ описує процес відповідального розкриття вразливостей у самому проєкті **DELMOS** (вихідний код, конфігурація за замовчуванням, залежності). Він відрізняється від [docs/security/SECURITY_SPECIFICATION.md](docs/security/SECURITY_SPECIFICATION.md), який описує архітектуру захисту даних усередині платформи.

## 1. Підтримувані версії

| Версія | Підтримка безпекових оновлень |
| --- | --- |
| Остання випущена мінорна версія (`vX.Y.*`) | ✅ Так |
| Попередні мінорні версії | ❌ Ні (рекомендовано оновлення, див. [docs/operations/UPGRADE_AND_ROLLBACK.md](docs/operations/UPGRADE_AND_ROLLBACK.md)) |

До досягнення першого стабільного релізу `v1.0.0` підтримується лише найсвіжіша опублікована версія.

## 2. Як повідомити про вразливість

**Не створюйте публічний issue для вразливостей безпеки.**

1. Використайте приватний механізм повідомлення GitHub — [«Report a vulnerability»](https://github.com/nick-fedchik/delmos/security/advisories/new) у вкладці Security репозиторію <https://github.com/nick-fedchik/delmos>.
2. Якщо приватний механізм недоступний, зверніться до відповідальних за проєкт через контакт, зазначений у [GOVERNANCE.md](GOVERNANCE.md).
3. Вкажіть: версію DELMOS, кроки відтворення, потенційний вплив, за наявності — proof-of-concept.

## 3. Очікуваний час реакції

| Етап | Цільовий термін |
| --- | --- |
| Підтвердження отримання повідомлення | 3 робочі дні |
| Первинна оцінка серйозності | 7 робочих днів |
| Випуск виправлення (для критичних вразливостей) | Найкращі зусилля, залежно від складності |

## 4. Розкриття інформації

Публічне розкриття деталей вразливості відбувається лише після випуску виправлення, за координації з особою, що повідомила про проблему (Coordinated Disclosure).

## 5. Область застосування

Ця політика стосується коду цього репозиторію. Питання щодо архітектури захисту даних експлуатованого екземпляра DELMOS — див. [docs/security/SECURITY_SPECIFICATION.md](docs/security/SECURITY_SPECIFICATION.md) та [docs/operations/](docs/operations/README.md).
