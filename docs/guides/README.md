## 2. Аудиторія

* **guides/** (корінь) — стратегічні документи для будь-кого, хто хоче зрозуміти напрямок продукту.
* **guides/developer/** — практичні інструкції для інженерів, що контриб'ютять код чи документацію.
* **guides/user/** — покрокові інструкції для кінцевих користувачів платформи (Project Manager, Requirements Engineer тощо).
