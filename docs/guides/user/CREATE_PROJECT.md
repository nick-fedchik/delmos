# DELMOS: як створити проєкт (Create a Project)

Дата: 2026-09-23. Статус: практичний посібник користувача.
Ліцензія: Apache 2.0.
Контекст: [use-cases: Project Manager](../../use-cases/PROJECT_MANAGER.md), [SHR-01: Generic Project Plan](../../requirements/stakeholder/SHR-01-generic-project-plan.md).

---

## 1. Передумови

* Обліковий запис із роллю Project Manager, призначеною системним адміністратором у межах програми (Programme).
* Визначена назва проєкту та коротка мета (обсяг робіт).

## 2. Кроки

1. Увійти в застосунок під обліковим записом Project Manager.
2. Натиснути **«Створити проєкт»** у розділі відповідної програми.
3. Вказати назву, короткий опис і зв'язок з батьківською програмою.
4. Обрати сховище артефактів (`RepositoryProvider`):
   * **Internal** — вбудоване сховище DELMOS (рекомендовано для початку роботи без додаткової конфігурації).
   * **Plain Git** — довільний Git-репозиторій по SSH/HTTPS.
   * **GitHub / GitLab / Azure Repos** — інтеграція з корпоративною платформою (потребує попереднього налаштування адміністратором, див. [use-cases: Administrator, ADM-008](../../use-cases/ADMINISTRATOR.md)).
5. Підтвердити створення проєкту.
6. Система атомарно створює проєкт разом з обов'язковим документом **Generic Project Plan** (`PLAN-001`) у стані `draft`.
7. Перейти на вкладку **Project Plan** та заповнити базові розділи: мета, обсяг робіт, команда (RACI).

## 3. Що далі

* Активувати необхідні модулі методології чи комплаєнсу — див. [use-cases: Project Manager, PM-004..PM-007](../../use-cases/PROJECT_MANAGER.md).
* Сформувати графік фаз і майлстоунів — `PM-008`, `PM-009`.
* Затвердити базовий кошторис (`PM-011`) та подати план на затвердження (`PM-013`, `PM-014`).
