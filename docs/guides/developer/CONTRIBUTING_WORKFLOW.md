# DELMOS: процес контриб'юції (Contributing Workflow)

Дата: 2026-09-23. Статус: практичний посібник контриб'ютора.
Ліцензія: Apache 2.0.
Контекст: [локальне середовище розробки](LOCAL_SETUP.md).

---

## 1. Стиль коду

* **Go (backend):** форматування через `gofmt`/`goimports`; лінтинг через стандартний набір `go vet` та узгоджений лінтер репозиторію. Пакети організовані за доменними межами (наприклад, `internal/specifications`, `internal/economics`), а не за технічним шаром (controllers/services/models).
* **Vue 3 / TypeScript (frontend):** Composition API з `<script setup lang="ts">`; стилізація через утилітарні класи дизайн-системи (`gl-*`) та токени, без довільних значень кольору/відступів.

## 2. Конвенції повідомлень комітів

```text
# Добре
Add composite specification hash validation
Fix outbox lease expiry race condition

# Погано
fix(spec): resolve bug
```

* Повідомлення коміту починається з великої літери, у наказовому способі (imperative mood), без префіксів на кшталт `feat:`/`fix:`.
* Посилання на задачі чи документи вимог наводяться повним ідентифікатором (`SWR-12`, `ADR-005`), а не скороченим номером задачі трекера.

## 3. Чек-лист перед відкриттям Merge Request

- [ ] Після появи Makefile: `make validate` пройдено без помилок; для поточної стадії документації цей пункт ще не застосовується.
- [ ] Нова або змінена поведінка відображена у відповідному документі `SWR-NN` / `SPEC-NN`, якщо змінює контракт.
- [ ] Додано юніт-тести для нової логіки; для наскрізних сценаріїв — оновлено відповідний `UAT-NNN` за потреби.
- [ ] Записи журналу (`journalctl`/логи) не містять секретів чи персональних даних понад мінімально необхідні.
- [ ] Документація (`docs/`) оновлена, якщо змінено контракт API, схему бази даних чи операційну процедуру.
- [ ] Якщо зміна впливає на випущену версію — додано запис у `CHANGELOG.md` за шаблоном [RELEASE-NOTES-TEMPLATE.md](../../templates/RELEASE-NOTES-TEMPLATE.md).

## 4. Перше звернення (First Contribution)

1. Ознайомитися з [VISION.md](../VISION.md) та [architecture/ARCHITECTURE.md](../../architecture/ARCHITECTURE.md).
2. Налаштувати локальне середовище за [LOCAL_SETUP.md](LOCAL_SETUP.md).
3. Обрати невелику, чітко окреслену задачу для першого внеску (виправлення документації чи ізольований баг-фікс).
4. Відкрити Merge Request з описом, що посилається на відповідний документ вимог чи задачу.
