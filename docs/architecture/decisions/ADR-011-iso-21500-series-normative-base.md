# ADR-011: Серія ISO 21500 як нормативна база керування проєктами й проєктної економіки

- **Статус:** Прийнято (Accepted)
- **Дата:** 2026-09-26
- **Контекст:** Документація DELMOS описує керування проєктами, ієрархічну структуру робіт і проєктну економіку, спираючись одночасно на три різні нормативні системи. У [ADR-006](ADR-006-project-economics-resource-accounting.md), [GLOSSARY.md](../GLOSSARY.md), [METRICS.md](../METRICS.md) та [MODULE_CATALOG.md](../MODULE_CATALOG.md) ті самі поняття виводяться то з PMBOK, то з SWEBOK, то з ISO 21502. Це створює три конкретні проблеми:
  1. **Немає єдиного джерела термінології.** Україномовні відповідники термінів добиралися довільно, без звіряння зі словником стандарту. Приклад: метод EVM усюди названо «освоєний обсяг» — це переклад, похідний від PMBOK, тоді як ДСТУ ISO 21508:2022 визначає його як **«управління здобутою цінністю»**.
  2. **Профільні стандарти серії не залучені.** Для методу освоєної цінності профільним документом серії є ISO 21508, для ієрархічної структури робіт — ISO 21511, для словника — ISO/TR 21506. Жоден з них у документації не згаданий, хоча відповідні поняття вже описані.
  3. **Ризик закріплення розбіжності в коді.** Фаза P5 (`management.resources`, `management.economics`) перетворює ці поняття на імена таблиць, колонок, ключів метрик і полів API-контракту. Розбіжність, не усунена в документації, стає незворотною в схемі даних.

- **Рішення:** Прийняти **серію ISO 21500** (розроблену технічним комітетом ISO/TC 258) за єдину нормативну базу керування проєктами, ієрархічної структури робіт і проєктної економіки в DELMOS.

  1. **Нормативні документи серії (normative).** Вимоги й терміни DELMOS виводяться з них:

     | Стандарт | Назва (ДСТУ, українською) | Область застосування в DELMOS |
     | --- | --- | --- |
     | ISO 21500:2021 | Управління проєктами, програмами та портфелями. Контекст та концепції | Парасолькові поняття проєкту, програми, портфеля |
     | ISO 21502:2020 | Управління проєктами, програмами та портфелями. Настанови щодо управління проєктами | Життєвий цикл, фази, шлюзи, практики керування |
     | ISO/TR 21506:2018 | Управління проєктами, програмами та портфелями. Словник | **Головне джерело укр/англ термінології** |
     | ISO 21508:2018 | Управління здобутою цінністю в управлінні проєктами та програмами | Метод здобутої цінності: PV, AC, EV, CV, SV, CPI, SPI, BAC, EAC |
     | ISO 21511:2018 | Ієрархічні структури робіт для управління проєктами та програмами | Декомпозиція робіт (WBS), звʼязок кошторису з елементами структури |

  2. **Довідкові джерела (informative).** PMBOK, SWEBOK, ASPICE MAN.3 та IAS 38 зберігаються в документації **виключно як довідкові**. Вони пояснюють галузеву практику й дають англомовні синоніми (наприклад, BCWS/BCWP/ACWP), але **не є джерелом виведення вимог DELMOS** і не визначають термінологію. Посилання на них супроводжується явною позначкою «довідково».

  3. **Правило термінології.** Україномовний термін для будь-якого поняття керування проєктами звіряється з ISO/TR 21506; якщо поняття є профільним для ISO 21508 або ISO 21511 — з відповідним стандартом. Довільний переклад заборонений. Англомовний оригінал наводиться в дужках при першому вживанні.

  4. **Правило ідентифікаторів у коді.** Машинні ідентифікатори (імена таблиць, колонок, ключі метрик, поля JSON) залишаються **англомовними** й відповідають англійському терміну стандарту (`earned_value`, `cost_baseline`, `work_breakdown_structure`). Українською ведеться лише документація та людиночитані підписи. Це відокремлює мовну редактуру від зміни контракту даних.

- **Наслідки:**
  - *Позитивні:* Єдине, зовнішньо верифіковане джерело термінології; відповідність ДСТУ для українських замовників і аудитів; усунення ризику закріпити розбіжність у схемі БД до початку фази P5; профільні стандарти (21508 для здобутої цінності, 21511 для ієрархічної структури робіт) дають готову структуру понять замість самостійного проєктування.
  - *Негативні / Компроміси:* Потрібна разова редактура наявних документів, зокрема заміна усталеного терміна «освоєний обсяг» на «здобута цінність», що на перший час знижує впізнаваність для читачів, звиклих до PMBOK. Компенсується тим, що англомовне позначення (EVM, Earned Value) наводиться поруч. Серія ISO 21500 є настановчою, а не сертифікаційною, тому відповідність їй не перевіряється зовнішнім органом і забезпечується внутрішньою дисципліною.

- **Альтернативи, які відхилено:**
  - *Залишити PMBOK як основу.* Відхилено: PMBOK не має офіційного українського перекладу зі статусом ДСТУ, тому не вирішує проблему термінології.
  - *Залишити всі три джерела рівноправними.* Відхилено: саме рівноправність і породила наявну розбіжність.
