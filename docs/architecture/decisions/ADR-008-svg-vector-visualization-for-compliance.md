# ADR-008: Використання векторної графіки (SVG / Vue Flow) для візуалізації графів та аудитів

- **Статус:** Прийнято (Accepted)
- **Дата:** 2026-09-23
- **Контекст:** Інженерна простежуваність (RTM-матриця), аналіз впливу змін (Change Impact Tree) та схеми життєвого циклу (FSM) вимагають наочного візуального аналізу. Растрові зображення (PNG/JPEG) або важкі веб-канваси на Canvas/WebGL ускладнюють масштабування тексту, не дозволяють аудиторам чітко розбирати дрібні шрифти при експорті та не адаптуються під дизайн-систему GitLab Pajamas.
- **Рішення:** Затвердити стандартизований стек на базі **векторної графіки (SVG)**:
  1. *Інтерактивне полотно у вебі:* використання легковагового SVG-компонента для Vue 3 (на базі бібліотеки `Vue Flow`) у дизайні GitLab Pajamas. Підтримка апаратного zoom/pan, мінімапи, динамічного підсвічування шляхів і колірного кодування ASIL.
  2. *Декларативні діаграми:* підтримка розмітки Mermaid (`graph LR`, `stateDiagram-v2`) для генерації SVG безпосередньо у Markdown-звітах.
  3. *Векторний експорт для сертифікації:* матриця трасованості та графи залежностей експортуються у стандартизований векторний формат **SVG** або векторний PDF. Текст, зв'язки та мітки залишаються 100% чіткими при будь-якому масштабуванні зовнішніми аудиторами (TÜV, intacs).
  4. *Безпека відображення:* бекенд вилучає заборонені вузли з графової видачі на рівні SQL до рендерингу в SVG DOM, унеможливлюючи витік засекречених артефактів.
- **Наслідки:**
  - *Позитивні:* Ідеальна якість та чіткість графіки для аудитів; малий розмір векторних файлів; природна інтеграція з CSS токенами Pajamas; захист від витоків інформації.
  - *Негативні / Компроміси:* Навантаження на DOM браузера при рендерингу понад 1000 вузлів; необхідність пагінації підграфів та обмеження глибини трасування (Layout Throttling).
- **Пов'язані вимоги:** SHR-12, SWR-38; специфікація [VECTOR_AND_GRAPH_DATA.md](../VECTOR_AND_GRAPH_DATA.md).
