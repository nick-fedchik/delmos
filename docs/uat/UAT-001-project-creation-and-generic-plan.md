# UAT-001: Створення проєкту з автоматичним Generic Project Plan

- **Статус:** Draft
- **Перевіряє вимоги:** `SHR-01` (Generic Project Plan), `SHR-09` (Work Item and Work Product)
- **Роль виконавця:** Project Manager (за сприяння System Administrator для попереднього кроку)
- **Версія платформи:** v0.1.0 (PoC)
- **Дата останнього виконання:** *Ще не виконано.*

---

## Передумови

- Розгорнутий екземпляр DELMOS, доступний виконавцю за HTTPS.
- Обліковий запис з роллю `System Administrator` вже створив програму (Programme) та призначив користувача відповідальним Project Manager (`ADM-006`).
- Виконавець автентифікований під роллю Project Manager.

## Кроки сценарію

1. Увійти в застосунок під обліковим записом з роллю Project Manager.
2. Перейти до розділу створення нового проєкту та вказати назву, короткий опис і батьківську програму.
3. На кроці вибору сховища артефактів (`RepositoryProvider`) обрати варіант **Internal (вбудоване сховище)** (`PM-002`).
4. Підтвердити створення проєкту.
5. Перейти на щойно створену сторінку проєкту та відкрити вкладку **Project Plan**.
6. Переконатися, що документ `PLAN-001` (Generic Project Plan) уже існує в стані `draft` без ручного втручання.
7. Відкрити розділ плану **Мета, обсяг робіт, команда (RACI)** та заповнити базові поля (`PM-003`).
8. Зберегти зміни та переконатися, що система створила нову ревізію плану.

## Очікувані результати

- Проєкт створюється атомарно разом із документом `PLAN-001` — не існує стану, коли проєкт присутній, а план відсутній.
- Прив'язка сховища (`RepositoryBinding`) створюється без спроби клонування зовнішнього репозиторію (оскільки обрано Internal).
- Ревізія плану після заповнення розділу RACI отримує новий номер версії, а попередня версія залишається доступною в історії.
- Жодна дія не повертає HTTP 5xx; усі помилки валідації (за їх наявності) супроводжуються зрозумілим повідомленням.

## Докази виконання (Evidence)

*Ще не виконано.* Після виконання сюди додається ідентифікатор створеного проєкту, знімки екрана вкладки Project Plan та посилання на журнал аудиту створення ревізії.
