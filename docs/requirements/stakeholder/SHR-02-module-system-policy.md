# SHR-02: Глобальне керування політиками модулів адміністратором

- **Ідентифікатор:** `SHR-02`
- **Стейкхолдери:** System Administrator, Security Officer, Compliance Manager.
- **Формулювання:** Системний адміністратор повинен мати єдиний інтерфейс перегляду та керування політиками доступності встановлених у системі модулів (Available, Blocked, Suspended) із контролем версій, маніфестів та топологічних залежностей.
- **Обґрунтування (Rationale):** Запобігання використанню несумісних або скомпрометованих версій розширень, централізований нагляд за ліцензіями та можливість екстреного вимкнення дефектних модулів на рівні всієї інсталяції.
- **Критерії приймання:**
  1. Модулі мають чіткі статуси політики (`ModuleSystemPolicy`).
  2. Режим `blocked_for_new_activation` забороняє нові підключення, але не ламає діючі проєкти.
  3. Режим `suspended` негайно блокує виконання залежних правил у рантаймі.

- **Пов'язані архітектурні рішення:** [ADR-004](../../architecture/decisions/ADR-004-two-tier-module-governance-generic-plan.md).
