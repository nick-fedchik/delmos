# SHR-01: Обов'язкова наявність Generic Project Plan для кожного проєкту

- **Ідентифікатор:** `SHR-01`
- **Стейкхолдери:** Project Manager, Programme Manager, Lead Systems Engineer, Auditor.
- **Формулювання:** Система повинна гарантувати, що будь-який створений проєкт автоматично та атомарно отримує головну структуровану конфігурацію — Project Plan (`PLAN-001`, тип `plan`, профіль `core:project_plan`), яку неможливо видалити. План є єдиним джерелом правди для базових процесів, фаз, віх, результатів та підключених модулів; стандарти, ресурси й бюджет з'являються лише через відповідні модулі.
- **Обґрунтування (Rationale):** Відсутність центрального конфігураційного документу призводить до фрагментації налаштувань, неузгодженості методологій та втрати контролю над проєктом. План є точкою інтеграції інженерії та бізнесу.
- **Критерії приймання:**
  1. Виклик команди створення проєкту створює запис проєкту та `PLAN-001` в одній транзакції.
  2. Проєкт без плану не може перейти у стан `active`.
  3. План містить машинно-валідований маніфест базових і модульних конфігураційних розділів; пояснювальний Markdown не замінює маніфест.
    4. У межах проєкту існує рівно один Project Plan; користувач або модуль не може
      створити другий Work Product з профілем `core:project_plan`.
