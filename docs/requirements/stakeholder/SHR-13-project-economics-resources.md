# SHR-13: Облік ресурсів, трудовитрат та проєктна економіка (EVM, P&L)

- **Ідентифікатор:** `SHR-13`
- **Стейкхолдери:** Project Manager, Financial Controller, Resource Manager, Delivery Director.
- **Формулювання:** Система повинна забезпечувати наскрізне планування місткості й завантаженості інженерних ресурсів, облік трудовитрат (Work Records), контроль базового кошторису (Cost Baseline) та фактичних витрат (Labor & Non-Labor), аналіз ефективності за методом освоєного обсягу (EVM) та комерційний аналіз (P&L/TCO) через спеціалізовані модулі економіки проєкту без перетворення ядра на бухгалтерську систему.
- **Обґрунтування (Rationale):** Інженерний проєкт нерозривно пов'язаний з бюджетом і термінами. Керівництво повинно мати математично обґрунтовані індекси виконання розкладу ($SPI$) та бюджету ($CPI$), оцінювати вартість запитів на зміни (CR) та контролювати ліміти фінансування на фазових шлюзах.
- **Критерії приймання:**
  1. Табельний облік фактичних годин через сутність `WorkRecord`.
  2. Планування зайнятості та місткості команд у FTE (`ResourceAllocation`) за календарями `WorkingCalendar`.
  3. Затвердження базового кошторису `CostBaseline` за статтями витрат (`Labor`, `Hardware`, `NRE`, `Licenses`, `Testing`, `Contingency`).
  4. Автоматичний розрахунок показників освоєного обсягу: $PV, AC, EV, CPI, SPI, EAC$.
  5. Правило `Funding Limit Gate` блокує відкриття наступної фази при перевищенні ліміту фінансування.
