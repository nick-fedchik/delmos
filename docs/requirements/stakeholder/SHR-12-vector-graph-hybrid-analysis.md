# SHR-12: Семантичний пошук та графова візуалізація зв'язків у PostgreSQL

- **Ідентифікатор:** `SHR-12`
- **Стейкхолдери:** Requirements Engineer, Safety Lead, Technical Project Leader, Auditor.
- **Формулювання:** Система повинна надавати можливість виявляти схожі або суперечливі вимоги й тести за допомогою векторного пошуку (`pgvector`), аналізувати топологію зв'язків та вплив змін за допомогою рекурсивних графів (`CTE CYCLE`) у єдиній базі даних PostgreSQL, а також візуалізувати графи простежуваності й схеми процесів засобами масштабованої векторної графіки (SVG).
- **Обґрунтування (Rationale):** Запобігання дублюванню інженерної роботи між командами, прискорення зв'язування вимог із тестами (Smart Suggestion), надійний каскадний аналіз впливу змін (Change Impact) та забезпечення читабельного векторного експорту для сертифікаційних аудитів.
- **Критерії приймання:**
  1. Семантичний пошук та фільтри прав доступу виконуються в єдиному SQL-запиті через `pgvector`.
  2. Обхід графа зв'язків захищений від нескінченних петель через нативний синтаксис `CYCLE`.
  3. Зміна джерела автоматично маркує залежні ребра прапорцем підозрілості (`is_suspect = true`).
  4. Інтерактивне полотно візуалізації на базі SVG підтримує zoom/pan, мінімапу, підсвічування шляхів і чистий векторний експорт у SVG та PDF.
  5. Проходження сценаріїв приймання `VEC-01..03`, `GRP-01..03`, `VIZ-01..02`.
