# SHR-03: Вибір і налаштування модулів менеджером у проєктному плані

- **Ідентифікатор:** `SHR-03`
- **Стейкхолдери:** Project Manager, Delivery Lead, Technical Project Leader.
- **Формулювання:** Проєктний менеджер повинен мати можливість у проєктному плані обирати активні для проєкту модулі з-поміж дозволених адміністратором, налаштовувати їхні параметри та змінювати цей вибір через формальний процес версіонування та погодження плану.
- **Обґрунтування (Rationale):** Кожен інженерний проєкт має власну специфіку (одним потрібен Scrum, іншим — суворий V-Model та ISO 26262). Налаштування процесів має фіксуватися в офіційному плані, а не через приховані тумблери в налаштуваннях БД.
- **Критерії приймання:**
  1. Інтерфейс редагування плану динамічно підтягує форми дозволених модулів.
  2. Активація модуля створює нову ревізію плану `PLAN-001`.
  3. Зміни набувають чинності лише після успішного виконання команди `plan.apply`.

- **Пов'язані архітектурні рішення:** [ADR-004](../../architecture/decisions/ADR-004-two-tier-module-governance-generic-plan.md).
