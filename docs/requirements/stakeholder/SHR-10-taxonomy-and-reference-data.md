# SHR-10: Керована класифікація, таксономії та довідкові дані

- **Ідентифікатор:** `SHR-10`
- **Стейкхолдери:** Information Architect, Safety Engineer, Compliance Specialist.
- **Формулювання:** Система повинна підтримувати контрольовані довідкові поняття та таксономічні ієрархії окремо від типів контенту та дозволів. Призначення таксономічних тегів чи категорій не повинно створювати автоматичних привілеїв доступу.
- **Обґрунтування (Rationale):** Класифікація артефактів (за підсистемами, компонентами, дисциплінами) має бути ациклічною, версійованою та не розмивати модель безпеки (RBAC).
- **Критерії приймання:**
  1. Підтримка плоских списків, дерев та поліієрархічних орієнтованих ациклічних графів (DAG).
  2. Перевірка відсутності циклів за допомогою SQL CTE `CYCLE`.
  3. Деактивація терміна словника не пошкоджує раніше зафіксовані історичні бейзлайни.
