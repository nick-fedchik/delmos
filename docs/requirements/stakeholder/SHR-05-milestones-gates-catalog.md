# SHR-05: Модель майлстоунів як керований каталог типів віх і правил

- **Ідентифікатор:** `SHR-05`
- **Стейкхолдери:** Project Manager, Quality Assurance Lead, Auditor.
- **Формулювання:** Майлстоуни та контрольні точки проєкту повинні моделюватися як типізовані об'єкти з контрольованого каталогу, що постачається ядром і модулями, де кожен тип віхи має специфічні правила приймання (acceptance criteria) та необхідні обов'язкові артефакти (deliverables).
- **Обґрунтування (Rationale):** Звичайна календарна дата не забезпечує інженерного контролю. Віха повинна гарантувати формальну перевірку зрілості результатів (Stage-Gate, CDR, PDR) із фіксацією рішення комісії.
- **Критерії приймання:**
  1. Каталог типів віх поповнюється модулями (наприклад, `aspice_gate_review`, `safety_concept_freeze`).
  2. Віха не може бути прийнята (`accepted`), якщо автоматична перевірка правил приймання виявила невиконані критерії.
  3. Закриття віхи генерує незмінний електронний запис `GateDecision`.
