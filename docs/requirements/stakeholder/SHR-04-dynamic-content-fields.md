# SHR-04: Конструктор структури контенту та динамічних полів

- **Ідентифікатор:** `SHR-04`
- **Стейкхолдери:** System Architect, Process Engineer, Domain Specialist.
- **Формулювання:** Система повинна дозволяти модулям додавати довільні типізовані властивості (поля) як до нових, так і до існуючих базових типів Work Products (вимог, тестів, архітектури) без зміни базової реляційної схеми БД.
- **Обґрунтування (Rationale):** Галузеві стандарти вимагають спеціалізованих атрибутів (наприклад, рівень ASIL за ISO 26262, рівень CAL за ISO 21434, статус DoR у Scrum). Зміна схеми БД під кожен стандарт руйнує стабільність ядра.
- **Критерії приймання:**
  1. Динамічні поля зберігаються в реляційній колонці `metadata` (JSONB) кожної ревізії.
  2. Валідація полів здійснюється за наданою модулем JSON Schema 2020-12.
  3. Деактивація модуля не видаляє раніше збережені поля в історичних ревізіях.
