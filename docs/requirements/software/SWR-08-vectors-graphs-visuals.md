# SWR-08: Системні вимоги до векторів, графів та візуалізації в PostgreSQL

Дата: 2026-09-23. Статус: нормативні вимоги підсистеми Vectors, Graphs & Visuals.  
Ліцензія: Apache 2.0.  
Батьківські вимоги: [SHR-12](../stakeholder/SHR-12-vector-graph-hybrid-analysis.md).  
Пов'язані архітектурні рішення: [ADR-001](../../architecture/decisions/ADR-001-all-in-postgresql-storage.md), [ADR-008](../../architecture/decisions/ADR-008-svg-vector-visualization-for-compliance.md).

#### SWR-36: Векторні ембедінги та гібридний семантичний пошук
1. Векторні представлення зберігаються в таблиці `wp_embeddings` за допомогою розширення `pgvector` із прив'язкою до точної пари `(work_product_id, revision_id, model_name)`.
2. Розрахунок векторів виконується асинхронно через подію `wp.revision_committed` та чергу outbox.
3. Пошук дублікатів та рекомендація тест-кейсів реалізуються єдиним гібридним SQL-запитом, що поєднує HNSW косинусну відстань (`<=>`) з фільтрами прав і класифікації. Acceptance: `VEC-01..03`.

#### SWR-37: Графовий аналіз зв'язків і простежуваність
1. Граф зв'язків зберігається в реляційній таблиці `trace_links` із типами відношень (`verifies`, `satisfies`, `refines`, `derives_from`) та прапорцем `is_suspect`.
2. Рекурсивний обхід графа виконується через `WITH RECURSIVE` з обов'язковим захистом від зациклень `CYCLE target_id SET is_cycle USING path`.
3. Оновлення джерела автоматично поширює прапорець `is_suspect = true` по графу залежностей (Change Impact Analysis). Acceptance: `GRP-01..03`.

#### SWR-38: Візуалізація графів і схем засобами векторної графіки
1. Візуалізація матриці RTM, дерев залежностей та FSM-схем здійснюється засобами масштабованої векторної графіки (SVG / Vue Flow) у дизайні GitLab Pajamas.
2. Підтримується масштабування, панорамування, міні-мапа, підсвічування шляхів, генерація Mermaid SVG та прямий векторний експорт для сертифікаційних аудитів (ASPICE, ISO 26262). Acceptance: `VIZ-01..02`.
