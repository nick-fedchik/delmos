Ліцензія: Apache 2.0.  
Батьківські вимоги: [SHR-08](../stakeholder/SHR-08-metrics-and-measurements.md).  
Пов'язані архітектурні рішення: [ADR-006](../../architecture/decisions/ADR-006-project-economics-resource-accounting.md).

#### SWR-21: Типізований реєстр метрик ядра
1. `MetricDefinition` підтримує типи: `integer`, `decimal`, `duration`, `boolean`, `enum`, `distribution`. Заборонено довільний нетипізований JSON як значення метрики.
2. Метрики мають суворі одиниці вимірювання (`count`, `percent`, `ms`, `currency:EUR`, `currency:USD`).

#### SWR-22: Модульні метрики й безпечне обчислення
1. Обчислення виконуються фоновими воркерами за версіованими вхідними даними. Браузерний віджет є лише споживачем значення, а не джерелом істини.
2. Результат вимірювання фіксується незмінною сутністю `MetricObservation` із зазначенням якості (`valid`, `stale`, `no_data`, `error`).
3. Застарілі або невалідні вимірювання блокують проходження обов'язкових фазових шлюзів (Gate Reviews).
