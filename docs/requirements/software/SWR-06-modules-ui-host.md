# SWR-06: Системні вимоги до модульної системи та Module UI Host

Дата: 2026-09-23. Статус: нормативні вимоги підсистеми Modules & UI Host.  
Ліцензія: Apache 2.0.  
Батьківські вимоги: [SHR-02](../stakeholder/SHR-02-module-system-policy.md), [SHR-03](../stakeholder/SHR-03-project-module-activation.md), [SHR-07](../stakeholder/SHR-07-engineering-artifacts-extensions.md).  
Пов'язані архітектурні рішення: [ADR-004](../../architecture/decisions/ADR-004-two-tier-module-governance-generic-plan.md).

---

#### SWR-15: Розширення інших Work Products функціональними модулями
1. Архітектура дозволяє створення модулів для будь-яких типів WP: семантичний аналіз дублікатів вимог, трекінг тестів, інтерактивна матриця RTM.

#### SWR-17: Постачання UI-внесків модуля
1. Модуль постачає UI schema або власні скомпільовані компоненти Vue 3 для відображення специфічних редакторів через Module UI Host. Заборонено підвантаження віддаленого динамічного JS.
2. Внески проходять перевірку на контрастність теми (Pajamas light/dark), доступність фокусу та адаптивність розмітки.

#### SWR-18: Сумісність, ізоляція та відтворюваність внесків
1. На інсталяцію активний один реліз коду модуля. Компіляція схем ізолює простори імен.
2. Історичні визначення та ревізії зберігаються для забезпечення повної відтворюваності бейзлайнів.
